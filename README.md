A **teach-from-zero** study guide for **Financial and Managerial Accounting, Class Test 1** —
**Chapter 1 (Basic Accounting)** and **Chapter 2 (The Recording Process)**. Written for someone who
missed the class and never opened the book, so you can learn it from scratch *and* answer the recall
questions the paper actually asks.

## Built for how this exam is actually marked

The paper is **20 marks — 5 fill-in-the-blanks, 5 short questions, 10 long questions** — and the
questions are heavily **factual**: exact terms, named bodies, precise definitions, specific figures.
Understanding the ideas is not enough on its own.

So every section closes with a **Hard Facts** table — term on the left, exactly what to write on the
right. Nine of them. That's the fill-in-the-blank insurance.

Journal entries, T-accounts, trial balances and financial statements are laid out in the **proper ruled
format** — Date / Account Titles and Explanation / Ref. / Debit / Credit, credits indented, three-line
statement headings, totals double-underlined — because presentation carries marks too.
